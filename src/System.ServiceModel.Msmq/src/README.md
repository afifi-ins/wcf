## About

The System.ServiceModel.Msmq package provides the types that permit SOAP messages to be exchanged using MSMQ (Microsoft Message Queuing) as the transport (example: NetMsmqBinding, MsmqIntegrationBinding).

This package is Windows-only.

### Installing the package:

Install System.ServiceModel.Msmq package from [Nuget.org](https://www.nuget.org/packages/System.ServiceModel.Msmq)

`dotnet add package System.ServiceModel.Msmq`

## How to use

See [WCF Samples](https://learn.microsoft.com/en-us/dotnet/framework/wcf/samples/) for samples on how to use NetMsmqBinding and MsmqIntegrationBinding.
